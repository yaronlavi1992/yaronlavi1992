## Ask my CV

This repository is also a small AI agent that answers questions about my experience.

- **Grounded:** it answers only from [`knowledge/`](knowledge/) and cites the section
  behind every claim.
- **Honest:** if a question isn't covered (salary, availability, skills I don't have), it
  says so instead of guessing.
- **Hardened:** questions are treated as data, so "ignore your instructions" doesn't work.
- **Provider-neutral:** runs on any OpenAI-compatible model, including a local one.
- **Measured:** every change runs the eval suite below. The numbers are regenerated by the
  suite itself, not typed by hand.
